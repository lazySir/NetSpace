## Scope and handling

The page footer offers an explicit download of the local SQLite database. The service uses SQLite's online backup API while holding the repository lock, writes to a uniquely named temporary directory, verifies the resulting database with PRAGMA integrity_check, streams it with Content-Length, and removes the temporary file after the response. The fixed-format download name is generated by the server; the endpoint rejects query parameters, accepts no destination path, retains the loopback Host/Origin checks, and returns a generic storage error to the browser instead of a filesystem path or SQL message.

The backup contains device profiles, network and scan history, change events, and settings. It may contain device names, IP/MAC addresses, and user notes. The browser saves it to the user's configured downloads location. This iteration adds no restore/overwrite action and no external upload or third-party dependency.
