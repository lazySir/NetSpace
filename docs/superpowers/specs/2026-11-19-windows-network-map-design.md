# Windows 局域网 3D 设备地图

用户已确认：发现真实同网设备，坐标允许模拟，并要求实现 Windows 版本。当前目录为空，在本目录创建独立应用。

采用 Windows 原生网络采集 + Python 标准库本地服务 + 离线 Three.js 页面。交付可双击运行的 Windows 可执行文件，同时保留源码和启动脚本。主界面为中文，左侧设备列表，中间 3D 网络图，右侧设备详情。支持网卡选择、重新发现、搜索、视角复位、自动旋转和 JSON 导出。

真实扫描默认开启，仅对用户选中的已连接 IPv4 网卡所属局域网发起 ARP 发现；较大网段默认主动扫描本机所在 /24，明确提示实际扫描范围。缓存邻居和本次地址解析成功分别标识；SendARP 可能直接使用系统缓存，因此解析成功不声称证明当前在线。节点位置为模拟布局，节点连线仅表示同网段关系，不声称还原交换机端口。演示模式必须显著标注，与真实结果隔离。未知名称不猜测，设备数不当作人数。

服务仅绑定 127.0.0.1，静态资源随应用打包，不使用在线 CDN。写入接口验证同源请求，扫描不可指定任意公网地址。PowerShell 命令隐藏窗口、读取 UTF-8 JSON，使用 SendARP 原生接口执行发现。关闭应用入口释放服务。

验证覆盖：网段边界、缓存与在线证据、网卡隔离、超大网段限制、API 错误和并发扫描、静态目录穿越；在本机做真实 Windows 扫描与浏览器交互检查，并验证打包后的可执行文件。
